# Starry Atelier artwork

`starry-night.jpg` is a 1280 × 1014 reproduction of Vincent van Gogh's *The Starry Night* (1889), sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg), where the reproduction is marked Public Domain. The theme crops and masks separate details; it does not place the complete painting behind the application.
